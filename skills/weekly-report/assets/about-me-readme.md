# About-Me/

Эта папка — источник для скила `personal-unpack`. Положите сюда файлы о себе, и скил разберёт их на структуру личного бренда.

Что стоит положить (можно не всё сразу):

1. **Факты** — резюме/CV, портфолио, описания кейсов и проектов, сертификаты.
2. **Публичный голос** — экспорты постов из Telegram/Instagram/LinkedIn или просто скопированные тексты постов, которые вы уже публиковали.
3. **Приватный голос** — заметки, дневниковые записи, переписки, черновики — всё, где вы пишете о себе не для публики.

Форматы: docx, pdf, txt, md — подойдёт почти всё, из чего можно вытащить текст.

Результат анализа появится в `About-Me/output/` — эту вложенную папку трогать не нужно, скил сам туда пишет.
